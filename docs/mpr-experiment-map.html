Ready-to-use conclusion

Our small-scale study supports the value of explicit evidence and sequential prompting. It exposes incomplete fact retrieval at long hops and no detectable overall answer gain from increasing top-k. Implicit and hybrid memory remain toy probes; their benchmark-level conclusions require further experiments.

Sources: paper v1, §§3.4–6; linked committed result summaries. Benchmark comparisons are qualitative; no paper-versus-ours accuracy delta is reported. Verify camera-ready changes before the final talk. T5 clarifies the sequential mechanism, T6 tests e5 formatting, and T7 checks sample stability; these extend existing evidence rather than fill missing method coverage.

Two guardrails from PR #1

Resource gate: before a new model or context size, test a real-context inference batch. Before training, complete train → save → reload → infer. Scientific gate: do not mix historical Farm results, T4 EM, retrieval recall and laptop contains scores into one ranking.
