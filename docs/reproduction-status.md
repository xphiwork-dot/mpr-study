# Reproduction status

What of the MPR paper (Explicit v.s. Implicit Memory, KDD '26) is reproduced in this repo, what is not, and
where the evidence is. This file is the single source of truth; the README only links here.

Sources for every number below: the committed files under `results/` (sections 1-5 and 6 for the Colab T4 run), or the scout report
(`docs/scout-report.html`, cited by section). The goal is to understand the paper's ideas, not to match its tables.
Setup the results were produced with: user 0 (13,100 statements, 2,700 questions), upstream commit `a24953c`.

Per-experiment deep-dives (paper counterpart, code walkthrough, provenance, how to run): `experiments/README.md` and the README in each `experiments/<folder>/`.

Status values: reproduced / partially / not reproduced.

## 2. Explicit memory on the LLM Farm (small run)

The farm patch (`experiments/01_farm_small_run/farm.patch`) adds an Azure OpenAI client for the Bosch LLM Farm to upstream `utils.py` and
`config.py`: credentials read from the environment at run time, `reasoning_effort=low`, and `temperature` dropped

## 6. Colab T4 runs (sessions 1, 2, 3a, 3b): Qwen2.5-7B-Instruct

Run on a free-tier Colab T4 with `Qwen/Qwen2.5-7B-Instruct-AWQ` (4-bit AWQ, fp16 compute) served by vLLM 0.32.0, greedy
decoding, with our own thin runner (`experiments/_shared/grid.py`) and the upstream NaiveReason / SequentialReason call flow and prompt
templates. Not the paper's setup: 4-bit weights, greedy decoding, our scorer (`experiments/_shared/score.py`), a slice over all 12 users
(100 questions per hop for hops 2-10, seed 0, `results/t4/slices/s900.json`) instead of user 0. Absolute numbers are not
comparable with the paper's tables. How to rerun: `experiments/_shared/README.md`. All numbers below are in the quoted files.

Issues found on the way, all fixed in the scripts and listed in `experiments/_shared/README.md` and `results/t4/timing_log.md`:
importing vllm in the Colab kernel starves the server of GPU memory; bm25s pulls in jax which preallocates the GPU; Colab's
torchao 0.10 is refused by peft 0.21; one e5 run failed on all questions (a bug in `grid.py`, rerun and fixed).

## What a Google Colab T4 could still add

Notes on the T4 sessions (all done). A free T4 has 16 GB VRAM, fp16 only, and sessions can be
cut, so all scripts write resumable output. Sessions 2 (SR grid), 3a (top-k) and 3b (step sweep) are done, see section 6; session 4 ran on the laptop instead. No T4 session of the plan is left.
`results/t4/estimates.md` explains how the estimates were made.

Not planned for a T4: TreeRAG and GraphRAG (the index build cost is in LLM calls, not GPU), and 7B LoRA with 50 adapters.
